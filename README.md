**Lanternkeep** is a tower-defence game about the last lighthouse on a dark coast. Every night the gloom — crawlers, swifts, bulwarks, wisps and the Gloom Lord himself — climbs the old stone road toward the light. You are the keeper: build lantern towers on the stone circles beside the road, upgrade them, sell them, and hold the light through all 12 waves.

Four lanterns, four jobs: **Ember** burns fast and cheap, **Frost** slows the gloom down, **Storm** lobs long-range splash shells, **Prism** throws chain lightning that jumps from foe to foe. Each upgrades twice, up to a crowned third level. Gold comes from kills and wave bonuses; starting a wave early pays a little extra. If the lighthouse falls, the night wins.

Everything is drawn in code on one canvas and every sound is a synthesized WebAudio tone — no images, no audio files, no network requests at all.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click a stone circle, pick a lantern (keys 1–4), and press Space to start a wave. P pauses, M mutes, F toggles 1×/2× speed, R restarts.
